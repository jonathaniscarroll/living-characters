# Living Characters — Virtual World

A browser-based shared world where felted and clay characters live on an interactive map. Built for **Art Camp: Living Characters & Virtual Worlds**.

## What it does

Participants place their handmade character on a shared map of named locations. Anyone can click a character to open their card — photo, animated GIF (from Mixamo), mood, items, and dialogue. The facilitator controls the map from one computer + projector; everyone else interacts on their own device if available, or watches the shared screen.

## Structure

```
index.html          ← the whole app (single file, no build step)
README.md
```

## Adding a character

1. Upload a photo of the physical character (felting or clay).
2. Export an animated GIF from Mixamo and upload it.
3. Fill in name, location, mood, and items.
4. The character pin appears on the map immediately.

## Deployment

Host on GitHub Pages or any static server. No backend required.
