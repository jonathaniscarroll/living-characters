🏠 Living Characters — Authoring Tool

This is the authoring interface for the Living Characters virtual world builder.

The full interactive tool (map, characters, rooms, GPS) lives at the root of this site during development.

When building for production, copy the full index.html into this author/ folder so it is deployed alongside the compiled Twine story.

✓ Build pipeline active — this folder is copied to build/author/ by GitHub Actions.
